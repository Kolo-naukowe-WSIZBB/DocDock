# app

Miejsce, gdzie wszystko się skleja. To jedyny folder, który zna wszystkie moduły.

## Co tu trafia

- implementacja usługi aplikacji, która łączy bazę i magazyn plików
- start aplikacji: konfiguracja, składanie modułów, ustawienia użytkownika
- testy end-to-end całej aplikacji

## Może korzystać z

Wszystkich modułów. Żaden inny moduł nie korzysta z `app/`.
