# contracts

Wspólny język wszystkich modułów.

## Co tu trafia

- interfejsy, które implementują moduły: baza, magazyn plików i usługa aplikacji
- typy danych (np. opis dokumentu) i typy błędów
- atrapy (fake'i) do testów i do pracy frontendu, zanim reszta będzie gotowa

## Czego tu nie ma

- logiki aplikacji
- odwołań do innych folderów

## Może korzystać z

Niczego. Wszystkie pozostałe moduły korzystają z tego folderu.
